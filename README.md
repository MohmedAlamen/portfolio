# Mohamed Alamen — Portfolio
Bilingual (AR/EN) Vue 3 + Bootstrap 5 + Vite. See `docs/ARCHITECTURE.md`.

```bash
npm install
npm run dev      # local dev
npm test         # unit/component tests
npm run build    # production build in dist/
```
Deploy: Settings → Pages → Source: **GitHub Actions**, then push to `main`.
Edit your data in `src/config/site.js`; put your photo at `public/assets/images/profile.jpg`.
